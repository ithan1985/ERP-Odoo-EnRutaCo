# ERP-Odoo EnRutaCo Business Lab

## Objetivo

Construir un laboratorio académico para estudiantes de Maestría donde Odoo sea utilizado como un Sistema de Información Empresarial para analizar procesos, información, capacidades organizacionales y transformación digital.

El objetivo NO es enseñar Odoo.

El objetivo es enseñar:

- Sistemas de Información
- Arquitectura Empresarial
- Procesos de negocio
- Gobierno de datos
- Transformación Digital
- Toma de decisiones

---

## Caso empresarial

La empresa utilizada es EnRutaCo S.A.S.

Sector:
Logística

Empleados:
1200

Facturación:
180.000 millones COP

Problemas:

- Sistemas desconectados
- ERP Legacy
- CRM en Excel
- Reportes manuales
- Baja trazabilidad
- Información duplicada

Los estudiantes actúan como consultores.

---

## Filosofía

Nunca desarrollar funcionalidades innecesarias.

Todo debe aportar al proceso de aprendizaje.

El código debe ser limpio.

La documentación debe ser completa.

Todo debe poder ejecutarse con Docker Compose.
