# ERP-Odoo EnRutaCo Business Lab

## Propósito

Este proyecto NO tiene como objetivo enseñar Odoo.

El objetivo es construir un laboratorio académico para estudiantes de Maestría donde un ERP sea utilizado como herramienta para comprender:

- Sistemas de Información
- Arquitectura Empresarial
- Procesos Organizacionales
- Gobierno de Datos
- Transformación Digital
- Toma de decisiones

El ERP es un medio, no el fin.

---

# Caso de estudio

La organización utilizada es EnRutaCo S.A.S.

Empresa colombiana de logística y transporte.

Características

- 1.200 empleados
- 18 ciudades
- 3 zonas francas
- crecimiento del 40%
- problemas de integración
- sistemas heredados
- información fragmentada

El caso completo se encuentra en:

/Caso/Caso EnRutaCo.pdf

---

# Perfil de los estudiantes

Maestría

No son desarrolladores.

No se espera que programen.

Se espera que analicen organizaciones y tomen decisiones.

---

# Filosofía

Todo desarrollo debe responder una pregunta de negocio.

Nunca agregar funcionalidades únicamente porque Odoo las permita.

Cada componente debe tener un propósito pedagógico.

---

# Objetivo del laboratorio

El estudiante debe ser capaz de responder preguntas como:

¿Cómo soporta un ERP un proceso de negocio?

¿Qué información necesita un gerente para tomar decisiones?

¿Cómo se integra un ERP con otros sistemas?

¿Qué capacidades empresariales soporta un ERP?

¿Cómo priorizar una transformación digital?

---

# Enfoque

El proyecto debe parecer una simulación de consultoría.

Los estudiantes asumirán el rol de consultores.

No serán usuarios finales del ERP.

---

# Calidad

Todo debe estar documentado.

El código debe ser sencillo.

Docker debe ser el mecanismo oficial de despliegue.

Toda configuración debe ser reproducible.

---

# Restricciones

No convertir el proyecto en un curso técnico de Odoo.

Evitar configuraciones innecesariamente complejas.

Priorizar claridad sobre complejidad.
