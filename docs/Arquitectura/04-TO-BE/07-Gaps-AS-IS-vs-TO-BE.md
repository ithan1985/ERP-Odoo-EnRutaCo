1. Introducción

El análisis de brechas permite identificar las diferencias entre la situación actual y el estado objetivo definido para EnRutaCo. Estas diferencias representan las oportunidades de transformación que deberán abordarse mediante proyectos, iniciativas organizacionales y soluciones tecnológicas.

2. Resumen Ejecutivo

El análisis evidencia que EnRutaCo deberá evolucionar en cinco dimensiones:

Negocio
Procesos
Aplicaciones
Datos
Tecnología

Cada brecha se encuentra relacionada con los requerimientos definidos durante el diagnóstico y con las capacidades del negocio priorizadas en la Arquitectura Objetivo.

12. Conclusión

El análisis de brechas confirma que la transformación requerida por EnRutaCo es integral y afecta todas las capas de la Arquitectura Empresarial. Las iniciativas resultantes deberán ejecutarse de manera coordinada para garantizar que la evolución del negocio, los procesos, las aplicaciones, los datos y la tecnología se mantenga alineada con los objetivos estratégicos definidos para la organización.
