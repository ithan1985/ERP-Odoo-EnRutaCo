# Visión

Construir el mejor laboratorio universitario en español para enseñar:

- Sistemas de Información
- Arquitectura Empresarial
- Transformación Digital
- Gobierno de Datos
- Procesos Organizacionales

utilizando un ERP como soporte para la toma de decisiones.

El estudiante no aprenderá a operar Odoo.

Aprenderá a dirigir organizaciones apoyadas por Sistemas de Información.
